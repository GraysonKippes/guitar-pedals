# Guitar Pedals
A collection of custom guitar pedals designed and built by me.
## Fuzzy Mk. 1
[Main Article](fuzz_mk1/)

A simple fuzz pedal, this is my first guitar pedal.
It amplifies the input signal and limits the output signal, shaping it into a more blocky, thick waveform.
The circuit consists of an op-amp amplifier-limiter circuit, as well as a 2:1 analog mux and an electronic toggle latch for bypass functionality.
It runs on 9VDC, which is standard for guitar pedals.
